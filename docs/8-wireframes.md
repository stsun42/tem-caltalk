## 글로벌 레이아웃 요소

모든 인증 후 화면에 공통 적용되는 레이아웃 요소.

```plaintext
┌────────────────────────────────────────────────────────────────────────────────┐
│  [LOGO] CalTalk   [ 팀 선택 드롭다운 ▼ ]            [ 🔔 3 ]  [ 김인선 ▼ ]  │
│                                                                                │
│  ① 로고: 홈(팀 목록)으로 이동                                                  │
│  ② 팀 선택 드롭다운: 소속 팀 전환, 팀 목록 이동                                │
│  ③ 알림 아이콘: 미읽음 배지(숫자), 클릭 시 알림 패널 열림                      │
│  ④ 사용자 메뉴: 사용자명 + 드롭다운 (로그아웃)                                 │
└────────────────────────────────────────────────────────────────────────────────┘
```

## 1. 로그인 페이지

**기능 ID**: F-002 (로그인/로그아웃)
**시나리오**: SC-02
**설명**: 비인증 사용자가 이메일과 비밀번호로 로그인하는 화면. 인증 성공 시 팀 목록 페이지로 이동.

```plaintext
┌────────────────────────────────────────────────────────────────────────────────┐
│                                                                                │
│                                                                                │
│                       ┌────────────────────────────┐                          │
│                       │                            │                          │
│                       │   [LOGO]  CalTalk          │                          │
│                       │   팀과 일정을 한 곳에서      │                          │
│                       │                            │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ 이메일                │  │  ← [1] 이메일 입력       │
│                       │  └──────────────────────┘  │                          │
│                       │                            │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ 비밀번호              │  │  ← [2] 비밀번호 입력     │
│                       │  └──────────────────────┘  │                          │
│                       │                            │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │      로그인           │  │  ← [3] 로그인 버튼       │
│                       │  └──────────────────────┘  │                          │
│                       │                            │                          │
│                       │  계정이 없으신가요?          │                          │
│                       │  [회원가입]                 │  ← [4] 회원가입 링크     │
│                       │                            │                          │
│                       └────────────────────────────┘                          │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

[오류 상태 - 인증 실패 시]
┌────────────────────────────────────────────────────────────────────────────────┐
│                       ┌────────────────────────────┐                          │
│                       │                            │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ user@example.com      │  │  ← 입력된 이메일 유지    │
│                       │  └──────────────────────┘  │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ ••••••••              │  │                          │
│                       │  └──────────────────────┘  │                          │
│                       │  ⚠ 이메일 또는 비밀번호가   │  ← [5] 오류 메시지       │
│                       │    올바르지 않습니다.        │                          │
│                       │                            │                          │
│                       └────────────────────────────┘                          │
└────────────────────────────────────────────────────────────────────────────────┘
```

**UI 요소 설명**
- [1] 이메일 입력 필드: type="email", placeholder="이메일을 입력하세요"
- [2] 비밀번호 입력 필드: type="password", placeholder="비밀번호를 입력하세요"
- [3] 로그인 버튼: Primary 버튼, 클릭 시 POST /auth/login 호출
- [4] 회원가입 링크: /signup 페이지로 이동
- [5] 오류 메시지: 401 응답 시 표시, 필드 구분 없이 동일 문구 표시 (보안)

## 2. 회원가입 페이지

**기능 ID**: F-001 (회원가입)
**시나리오**: SC-01
**설명**: 신규 사용자가 이름, 이메일, 비밀번호를 입력하여 계정을 생성하는 화면.

```plaintext
┌────────────────────────────────────────────────────────────────────────────────┐
│                                                                                │
│                       ┌────────────────────────────┐                          │
│                       │                            │                          │
│                       │   [LOGO]  CalTalk          │                          │
│                       │   팀 협업을 시작하세요       │                          │
│                       │                            │                          │
│                       │  이름                       │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ 홍길동                │  │  ← [1] 이름 입력         │
│                       │  └──────────────────────┘  │                          │
│                       │                            │                          │
│                       │  이메일                     │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ user@example.com      │  │  ← [2] 이메일 입력       │
│                       │  └──────────────────────┘  │                          │
│                       │                            │                          │
│                       │  비밀번호                   │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ ••••••••              │  │  ← [3] 비밀번호 입력     │
│                       │  └──────────────────────┘  │                          │
│                       │  8자 이상, 영문+숫자+특수문자 │  ← [4] 비밀번호 안내     │
│                       │                            │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │      회원가입          │  │  ← [5] 회원가입 버튼     │
│                       │  └──────────────────────┘  │                          │
│                       │                            │                          │
│                       │  이미 계정이 있으신가요?     │                          │
│                       │  [로그인]                   │  ← [6] 로그인 링크       │
│                       │                            │                          │
│                       └────────────────────────────┘                          │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

[유효성 검사 오류 상태]
┌────────────────────────────────────────────────────────────────────────────────┐
│                       │  이메일                     │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ user@example.com      │  │  ← 빨간 테두리 표시      │
│                       │  └──────────────────────┘  │                          │
│                       │  ⚠ 이미 사용 중인 이메일입니다 │  ← [7] 필드별 오류    │
│                       │                            │                          │
│                       │  비밀번호                   │                          │
│                       │  ┌──────────────────────┐  │                          │
│                       │  │ ••••••••              │  │  ← 빨간 테두리 표시      │
│                       │  └──────────────────────┘  │                          │
│                       │  ⚠ 비밀번호는 8자 이상,     │  ← [7] 필드별 오류       │
│                       │    영문+숫자+특수문자 포함   │                          │
└────────────────────────────────────────────────────────────────────────────────┘
```

**UI 요소 설명**
- [1] 이름: 필수 입력, 1자 이상
- [2] 이메일: 필수 입력, 이메일 형식 검증, 중복 시 409 오류
- [3] 비밀번호: 필수 입력, 마스킹 처리
- [4] 비밀번호 정책 안내: 항상 표시 (오류 전에도)
- [5] 회원가입 버튼: POST /auth/register 호출, 성공 시 로그인 페이지 이동
- [6] 로그인 링크: /login 페이지로 이동
- [7] 필드별 오류: 서버 응답 또는 클라이언트 검증 결과 표시

## 3. 팀 목록 페이지

**기능 ID**: F-003 (팀 생성), F-004 (팀 조회)
**시나리오**: SC-04
**설명**: 로그인 후 최초 진입 화면. 소속된 팀 목록을 카드 형태로 표시하고 새 팀 생성 진입점 제공.

```plaintext
┌────────────────────────────────────────────────────────────────────────────────┐
│  [LOGO] CalTalk                                    [ 🔔 2 ]  [ 김인선 ▼ ]   │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  내 팀 목록                                    [ + 팀 생성 ]  ← [1]           │
│                                                                                │
│  ┌───────────────────────┐  ┌───────────────────────┐  ┌──────────────────┐  │
│  │                       │  │                       │  │                  │  │
│  │  🏷 프로덕션 팀        │  │  🏷 사이드 프로젝트    │  │  +               │  │
│  │                       │  │                       │  │  새 팀 만들기     │  │
│  │  👑 팀장              │  │  👤 팀원               │  │                  │  │
│  │  멤버 5명             │  │  멤버 3명              │  │                  │  │
│  │                       │  │                       │  │                  │  │
│  │  [ 캘린더 보기 ]      │  │  [ 캘린더 보기 ]      │  │                  │  │
│  │                       │  │                       │  │                  │  │
│  └───────────────────────┘  └───────────────────────┘  └──────────────────┘  │
│       ↑ [2]                       ↑ [3]                      ↑ [4]           │
│                                                                                │
│  ─────────────────────────────────────────────────────────────────────────    │
│                                                                                │
│  받은 초대                                                                     │
│                                                                                │
│  ┌────────────────────────────────────────────────────────────────────────┐   │
│  │  📨 "디자인 스쿼드" 팀에서 초대가 왔습니다.  (3일 후 만료)             │   │
│  │                                          [ 수락 ]  [ 거절 ]            │   │
│  └────────────────────────────────────────────────────────────────────────┘   │
│       ↑ [5]                                                                    │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

**UI 요소 설명**
- [1] "+ 팀 생성" 버튼: 클릭 시 팀 생성 모달 열림
- [2] 팀 카드 (팀장): 팀명, 역할 배지(왕관 아이콘), 멤버 수, "캘린더 보기" 버튼
- [3] 팀 카드 (팀원): 팀명, 역할 배지(사람 아이콘), 멤버 수, "캘린더 보기" 버튼
- [4] 빈 슬롯: 팀 생성 진입점 (카드 형태 유지)
- [5] 초대 알림 배너: Pending 상태 초대 목록, 수락/거절 버튼 (F-006)

## 4. 팀 생성 모달

**기능 ID**: F-003 (팀 생성)
**시나리오**: SC-04
**설명**: 팀 목록 페이지에서 "+ 팀 생성" 버튼 클릭 시 나타나는 모달. 팀 이름을 입력하고 생성.

```plaintext
┌────────────────────────────────────────────────────────────────────────────────┐
│  [배경: 팀 목록 페이지 - 어둡게 처리]                                          │
│                                                                                │
│             ┌────────────────────────────────────────┐                         │
│             │                                        │                         │
│             │  팀 생성                          [ X ]│  ← [1] 닫기 버튼        │
│             │  ────────────────────────────────────  │                         │
│             │                                        │                         │
│             │  팀 이름                               │                         │
│             │  ┌──────────────────────────────────┐  │                         │
│             │  │ 예: 프로덕션 팀                   │  │  ← [2] 팀 이름 입력     │
│             │  └──────────────────────────────────┘  │                         │
│             │  팀 이름은 필수 항목입니다.             │  ← [3] 안내 문구         │
│             │                                        │                         │
│             │  ┌───────────┐  ┌───────────────────┐  │                         │
│             │  │  취소     │  │      생성하기      │  │  ← [4] 액션 버튼        │
│             │  └───────────┘  └───────────────────┘  │                         │
│             │                                        │                         │
│             └────────────────────────────────────────┘                         │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

[오류 상태 - 팀 이름 미입력]
│             │  팀 이름                               │
│             │  ┌──────────────────────────────────┐  │
│             │  │                                  │  │  ← 빨간 테두리
│             │  └──────────────────────────────────┘  │
│             │  ⚠ 팀 이름을 입력해주세요.              │  ← [5] 오류 메시지
```

**UI 요소 설명**
- [1] 닫기 버튼(X): 모달 닫기, ESC 키도 동일 동작
- [2] 팀 이름 입력: 필수 입력, 최소 1자, 자동 포커스
- [3] 안내 문구: 기본 상태에서 표시, 오류 시 오류 메시지로 전환
- [4] 취소/생성 버튼: 취소는 모달 닫기, 생성은 POST /teams 호출
- [5] 오류 메시지: 빈 이름으로 제출 시 표시 (400 Bad Request)

## 5. 팀원 초대 모달

**기능 ID**: F-005 (팀원 초대)
**시나리오**: SC-05
**설명**: 팀장이 팀원 이메일을 입력해 초대를 발송하는 모달. 팀 설정 또는 캘린더 상단 메뉴에서 진입.

```plaintext
┌────────────────────────────────────────────────────────────────────────────────┐
│  [배경: 어둡게 처리]                                                            │
│                                                                                │
│          ┌──────────────────────────────────────────────────┐                  │
│          │                                                  │                  │
│          │  팀원 초대                                  [ X ] │  ← [1]          │
│          │  ─────────────────────────────────────────────   │                  │
│          │                                                  │                  │
│          │  이메일로 팀원을 초대합니다.                       │                  │
│          │  초대받은 사람이 수락하면 팀원으로 합류합니다.      │                  │
│          │                                                  │                  │
│          │  초대할 이메일                                    │                  │
│          │  ┌────────────────────────────┐  ┌────────────┐  │                  │
│          │  │ teammate@example.com        │  │  초대 발송  │  │  ← [2] [3]     │
│          │  └────────────────────────────┘  └────────────┘  │                  │
│          │                                                  │                  │
│          │  ─────────────────────────────────────────────   │                  │
│          │  발송된 초대 목록                                  │  ← [4]          │
│          │                                                  │                  │
│          │  ┌──────────────────────────────────────────┐    │                  │
│          │  │  lee@example.com      Pending   [취소]    │    │  ← [5]          │
│          │  ├──────────────────────────────────────────┤    │                  │
│          │  │  park@example.com     Accepted  ✓         │    │  ← [6]          │
│          │  ├──────────────────────────────────────────┤    │                  │
│          │  │  kim@example.com      Declined  ✗         │    │  ← [7]          │
│          │  └──────────────────────────────────────────┘    │                  │
│          │                                                  │                  │
│          │                              [ 닫기 ]            │  ← [8]          │
│          │                                                  │                  │
│          └──────────────────────────────────────────────────┘                  │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

[오류 상태]
│          │  ┌────────────────────────────┐  ┌────────────┐  │
│          │  │ someone@example.com         │  │  초대 발송  │  │
│          │  └────────────────────────────┘  └────────────┘  │
│          │  ⚠ 이미 대기 중인 초대가 있습니다.                │  ← [9] 중복 초대
│          │  또는                                             │
│          │  ⚠ 등록되지 않은 이메일입니다.                   │  ← [10] 미가입
```

**UI 요소 설명**
- [1] 닫기 버튼: 모달 닫기
- [2] 이메일 입력 필드: 초대할 사용자 이메일, 형식 검증
- [3] "초대 발송" 버튼: POST /teams/{id}/invitations, 팀장만 표시
- [4] 발송된 초대 목록 섹션: 기존 초대 현황 표시
- [5] Pending 상태: 노란 배지, 취소 버튼 표시 (v1.1 이후)
- [6] Accepted 상태: 초록 배지, 체크 아이콘
- [7] Declined 상태: 빨간 배지, X 아이콘
- [8] 닫기 버튼: 모달 닫기
- [9] 중복 초대 오류: BR-25 적용, 409 응답
- [10] 미가입 오류: 404 응답 시 표시

## 6. 알림 패널
